# Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal number support
- Clear all (AC)
- Delete last digit (DEL)
- Calculate result (=)
- Handles division by zero

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

No installation or extra dependencies are required.

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## Project Structure

```text
calculator/
├── index.html
├── README.md
└── .gitignore
```

## How to Use

1. Click the number buttons to enter a number.
2. Choose an operation (+, -, ×, ÷).
3. Enter the second number.
4. Press (=) to calculate the result.
5. Press (AC) to clear everything.
6. Press (DEL) to delete the last digit.
